The wordmark is **Opaq**, capital O, the rest lowercase, set in Funnel Display. Never "OPAQ" in running text, never "Opaq AI".

| On yellow | `#14110A` | Text and icons on a yellow ground (white is not readable there) |

## Type

- **Funnel Display**: headings and the wordmark
- **Inter**: everything else

## Please

- Keep clear space around the mark of at least a quarter of its width.
- Use it on dark backgrounds. Do not recolor, stretch, rotate or add effects.
- Do not use the mark in a way that suggests endorsement or partnership without asking us.
